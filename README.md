# Nav&More offline maps

Full street-level vector map of Saudi Arabia as a single PMTiles file,
used by the Nav&More app for offline maps.

Latest file: https://github.com/imalhrbi/navandmore-maps/releases/latest/download/saudi-arabia.pmtiles

Built monthly by GitHub Actions with [Planetiler](https://github.com/onthegomap/planetiler)
(OpenMapTiles schema, zoom 0–14).

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the ODbL.
